# بيت مواد البناء

Build a professional Arabic Building Materials Store website.

The entire website must be in Arabic and use RTL (Right-to-Left) layout.

Focus only on the essential features below to keep the project simple and avoid unnecessary complexity.

1. الصفحة الرئيسية

تصميم احترافي وحديث.

شريط بحث عن المنتجات.

أقسام مواد البناء.

منتجات مميزة.

زر "تصفح المنتجات".

زر "احجز طلبك".

معلومات التواصل.

موقع المحل.

ملاحظات اختيارية

لا تطلب إنشاء حساب للعميل.

5. تأكيد الحجز

بعد إرسال الطلب:

إنشاء رقم طلب فريد.

عرض تفاصيل الطلب.

عرض تاريخ ووقت الاستلام.

عرض موقع المحل.

عرض حالة الطلب.

الحالة الأولية:

تم استلام الطلب

6. تتبع الطلب

إنشاء صفحة "تتبع الطلب".

يدخل العميل رقم الطلب ويظهر له:

تم استلام الطلب → تم تأكيد الطلب → جاري تجهيز الطلب → الطلب جاهز للاستلام → تم الاستلام
